# How to Create a Free Online Course with GitHub Pages and Embedin

Did you know you can create and publish your own online course for free using GitHub Pages and Embedin?

In this tutorial, I'll show you how to use GitHub Pages to host your website and Embedin to create and publish an interactive online course directly on your website — without managing servers or paying for website hosting.

With this combination, you can:
Create and publish your own online courses.
Host your website for free using GitHub Pages.
Embed interactive courses directly into your website.
Organize lessons and educational content.
Give your students an engaging learning experience.

Why pay for expensive hosting when you can get started for free?
